# DOCX 표 데이터를 RAG 검색에 포함하기

## 문제

소득세법 DOCX 문서로 RAG를 실습하면서, 세율표가 검색 근거에 제대로 포함되지 않는 문제를 겪었다. 본문만으로는 표에 담긴 과세표준과 세율의 관계를 전달하기 어려웠다.

이 문제는 Word 프로그램 자체가 표를 읽지 못하는 문제가 아니라, DOCX에서 검색용 텍스트를 추출하고 구성하는 과정에서 표 데이터를 충분히 반영하지 못한 문제로 정리했다. 기존 로더가 모든 표 텍스트를 누락한다고 단정하지는 않는다. 텍스트가 추출되더라도 행·열 관계가 사라질 수 있기 때문이다.

## 탐색 → 해결

1. 문서를 Markdown으로 변환하는 방법과 DOCX의 표를 직접 읽을 수 있는 라이브러리를 탐색했다.
2. `python-docx`를 사용해 문단과 표를 구분하여 처리하는 방식으로 변경했다.

   ```python
   from docx import Document as DocxDocument
   from docx.text.paragraph import Paragraph
   from docx.table import Table
   ```

3. 문단과 표를 문서 순서대로 처리하고, 표의 셀 내용을 Markdown 형태로 구성하여 검색용 텍스트에 포함했다.
4. 변경된 추출 결과로 문서를 분할하고 임베딩·저장한 뒤 검색 결과를 확인했다.

위 import 자체로 문제가 해결되는 것은 아니다. 실제 해결은 문단·표 순회 및 표 텍스트 변환 로직에 있다.

## 확인한 결과

작성자의 로컬 실행 결과에서 제55조 검색 문서에 `종합소득 과세표준 | 세율` 형태의 Markdown 표가 포함되는 것을 확인했다. 이는 해당 세율표가 추출·색인·검색되는 경로에 포함되었음을 보여준다.

다만 모든 표의 추출 정확도나 답변 품질 개선을 정량 평가한 것은 아니다. 병합 셀·중첩 표·이미지 형태의 표까지 모두 해결했다고 주장하지 않는다.

## 배운 점

RAG에서 필요한 근거가 검색되지 않을 때는 검색 모델뿐 아니라 원문 → 텍스트 추출 → 분할 → 색인 과정을 확인해야 한다. 표는 숫자를 가져오는 것과 행·열의 관계를 보존하는 것이 별개의 문제다.

## 저장소 반영 상태

이 기록은 작성자가 설명한 수정 내용과 로컬 실행 결과를 기준으로 한다. 기록 작성 시점(2026-11-11)의 GitHub 기본 브랜치에는 기존 `Docx2txtLoader` 기반 코드가 있으며, 수정된 파서 코드는 아직 반영되지 않았다. 이 문서 추가로 실행 코드를 변경하지 않았다.
